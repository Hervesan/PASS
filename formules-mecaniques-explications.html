Le fil qui relie tout : ΔW = σ.ΔS → Laplace ΔP = 2σR (goutte) ou 4σR (bulle) → Jurin ρgh = 2σr (× cos α si mouillage imparfait).
Moyens mnémotechniques
  • Goutte = 1 interface = 2σ ; bulle = 2 interfaces = 4σ.
  • Petit rayon = grosse surpression : la petite bulle se vide dans la grande.
  • Surfactant : σ ↓ → surpression ↓ → les petites alvéoles ne se vident plus.
  • Jurin : tube fin → le liquide monte haut (r au dénominateur).
  • Mouillage imparfait (ou calotte) : on ajoute cos α.
  • σ en N.m⁻¹ = force par longueur = énergie par surface.
