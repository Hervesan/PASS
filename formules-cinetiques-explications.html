Le fil qui relie tout : J = dNdt → Fick J = −D.S.∂C∂x avec D = kT6πrη → membrane J = D.Sp.ΔCh (× (1 − σ) si sélective) → filtration Jv,f = Np.π.a⁴8η.h.ΔP.
Moyens mnémotechniques
  • Fick : le signe − = le flux vide le milieu le plus concentré.
  • D = kT / 6πrη : chaud ↑, gros ↓, visqueux ↓ (T en haut, r et η en bas).
  • σ = 1 : que l'eau passe ; σ = 0 : zéro obstacle, tout passe.
  • Membrane : ∂C/∂x devient simplement ΔC / h.
  • Surface des pores = Np × disque πa².
  • Filtration : rayon à la puissance 4 → doubler le rayon multiplie le débit par 16.
  • Diffusion : les solutés vont du + concentré vers le − ; osmose : l'eau va du − concentré vers le +.
  • Deux compartiments égaux : on partage → x/2.
