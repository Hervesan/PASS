Le fil qui relie tout : Cn(H2O)n → aldose : n − 2 C* → 2n stéréoisomères → pont C1–C5 : cycle à 6 atomes (pyranose) → mutarotation +113° → +53° (β 64 % · α 36 %).
Moyens mnémotechniques
  • Aldose : n − 2 C* ; cétose : n − 3 C* (il a un alcool primaire de plus).
  • Stéréoisomères = 2 puissance le nombre de C*, pas le nombre de carbones.
  • Aldoses : tri 2, tétra 4, penta 8, hexa 16 (on double à chaque carbone).
  • Toujours moitié D, moitié L.
  • Pont en C5 → 6 atomes → pyrane ; pont en C4 → 5 atomes → furane.
  • β majoritaire (64 %) car moins encombré ; α a le plus grand angle (+113°).
  • Mutarotation : 113 → 53, le 3 reste.
  • Hémiacétalisation : 0 atome perdu ; méthylation, liaison osidique, lactone : 1 H₂O libérée.
  • Hexokinase → phosphate en 6 → glucose-6-phosphate.
