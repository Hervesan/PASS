Le fil qui relie tout : pH = −log[H3O⁺] → Ka / pKa → tampon pH = pKa + log [A⁻][AH] → sang pH = pK + log [HCO₃⁻]0,03 × PCO₂.
Moyens mnémotechniques
  • Ke = 10⁻¹⁴ → pH + pOH = 14 → eau pure à 25 °C : 10⁻⁷ mol/L.
  • Acide fort : −log c ; base forte : 14 + log c (effet miroir).
  • Acide faible : ½(pKa − log c) ; base faible : 7 + ½(pKa + log c) (signe inversé et + 7).
  • En dessous du pKa, c'est l'acide AH qui domine.
  • Tampon : la base en haut, l'acide en bas : log [A⁻]/[AH].
  • Demi-équivalence = moitié transformée = pH = pKa.
  • Sang : pH 7,35-7,45 et PCO₂ 35-45 mmHg : mêmes chiffres 35/45 !
  • Respiratoire = CO₂ = poumons ; métabolique = HCO₃⁻ = reins ; la compensation vient toujours de l'autre organe.
  • Hypoventilation → CO₂ retenu → PCO₂ ↑ → pH ↓.
