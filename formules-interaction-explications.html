Le fil qui relie tout : E = hν = hc/λ → ionisant si E > 12,4 eV → particules : TLE = dE/dx ; photons : photoélectrique Ec = E − El, Compton E = Ec + Edif, paires (> 1,022 MeV) → faisceau N = N0e−μx, μ = τ + σ + π, N(nCDA) = N0/2n → dose D = dE/dm.
Moyens mnémotechniques
  • Ionisant : E > 12,4 eV ⇔ λ < 0,1 µm = 100 nm ; les UV ne le sont pas.
  • Photo-électrique = photon + électron, total ; Compton = partiel + photon diffusé ; paires = photon + noyau.
  • Seuil des paires : 1,022 MeV = 2 × 511 keV.
  • Photoélectrique : Ec = E − El (tout part) ; Compton : E = Ec + Edif (partage).
  • CDA = ln 2 / μ.
  • CDA = « période » dans l'épaisseur : ÷ 2 à chaque CDA.
  • τ ∝ Z³/E³ : le plomb (Z élevé) arrête bien les basses énergies.
  • μ = τ + σ + π : chaque effet ajoute sa part.
  • Neutrons : σtot = σabs + σdiff.
