Le fil qui relie tout : PV = nRT et U = 32 RT → Q = m.C.ΔT et W = −P.ΔV → ΔU = Q + W → à P constante ΔH = Qp (H = U + PV) → mesure ΔH = m.Cp.ΔT ou loi de Hess.
Moyens mnémotechniques
  • T(K) = T(°C) + 273,15 : jamais de kelvins négatifs.
  • ΔU = Q + W : tout ce qui entre dans le système est positif.
  • W = −PΔV : le « − » rend W positif quand on comprime (ΔV < 0).
  • Volume constant → ΔU = Qv ; Pression constante → ΔH = Qp.
  • « H = U plus PV ».
  • Fonctions d'état (U, H) : ΔX = 0 sur un cycle ; Q et W dépendent du chemin.
  • 1 cal = 4,18 J ; eau : 1 cal.g−1.K−1.
  • 1 L d'eau : +1 °C par kcal, +0,24 °C par kJ.
  • Hess : on additionne les étapes comme des équations (CO : ΔH = ΔH1 − ΔH2).
