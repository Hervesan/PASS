Le fil qui relie tout : μJ = γJ → dans B₀ : ω₀ = γB₀ → ν₀ = γB₀ / 2π → ΔE = γħB₀ = hν₀ → résonance : ERF = hνRF = ΔE, λRF = c / ν₀ → relaxation : Mz(t) = Mz0(1 − e−t/T₁) et Mx,y(t) = − Mx,y,0 e−t/T₂ → IRM : I = K B₀ ρ (1 − e−TR/T₁) e−TE/T₂, une image de N lignes en N × TR.
Moyens mnémotechniques
  • γ en MHz.T⁻¹ ? alors ν₀ = γ × B₀ ; γ en rad.s⁻¹.T⁻¹ → ν₀ = γB₀ / 2π.
  • ¹H : 42,5 MHz par tesla ; ν₀ ∝ B₀ et ∝ γ.
  • ω₀ (rad/s) = 2π ν₀ (Hz) : la pulsation porte le 2π.
  • ν₀, ω₀, ΔE augmentent avec B₀ ; λRF diminue quand B₀ augmente (λ = c / ν₀).
  • Résonance : ERF = hνRF = ΔE = hν₀ → l'onde RF oscille à ν₀.
  • 2J + 1 états : J = ½ → 2 · 1 → 3 · 3/2 → 4 · 5/2 → 6.
  • 63 % repoussé à T₁ (87 % à 2T₁, total à 5T₁) ; 37 % restant à T₂ (13 % à 2T₂).
  • Tissus : T₁ 500-1000 ms, T₂ 50-100 ms (÷ 10).
  • SES : 90° à 0 · 180° à TE/2 · mesure à TE ; image de N lignes = N × TR.
  • Dans I : TR va avec T₁, TE va avec T₂.
