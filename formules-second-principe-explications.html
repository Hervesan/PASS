Le fil qui relie tout : isolé, ΔU = Q + W = 0 ne donne pas le sens → désordre S = kB.ln(Ω) → dS = δQrévT → isolé ΔS ≥ 0 → on ajoute le facteur énergétique : ΔG = ΔH − TΔS → spontané si ΔrG < 0 → ΔG = ΔG° + R.T.ln Q → équilibre ΔG° = −R.T.ln Kéq → K et T : Van't Hoff.
Moyens mnémotechniques
  • S = kB ln Ω : plus d'états possibles = plus de désordre = plus d'entropie.
  • Ω = 1 → ln 1 = 0 → S = 0 (ordre parfait, 0 K).
  • Solide < liquide < gaz : l'entropie suit le désordre.
  • « e » comme échangée (δQ/T), « c » comme créée (jamais négative).
  • Réversible : rien de créé (δSc = 0) ; irréversible : δSc > 0.
  • Isolé : pas d'échange → S ne peut que monter ou stagner (ΔS ≥ 0).
  • Fusion, évaporation : ΔH > 0 donc ΔS = ΔH/T > 0.
  • Gibbs : ΔU = TΔS − PΔV.
  • G = H − TS (pas U − TS) ; ΔG = ΔH − TΔS : convertir ΔH en J.
  • ΔG < 0 = exergonique = ça sort tout seul (sens 1).
  • Q : instant quelconque ; K : à l'équilibre (ΔG = 0, Q = K).
  • ΔG° = −RT ln K : ΔG° < 0 ⇔ K > 1 ; K jamais nulle.
  • Kp = Kc(RT)Δn, Δn = gaz produits − gaz réactifs.
  • Van't Hoff : endothermique → K monte avec T.
