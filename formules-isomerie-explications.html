Le fil qui relie tout : CnH2n+2 → N = 2C + T + 2 − H2 → carbone asymétrique C* → [α] = αl × c (racémique : α = 0) → 2n, 2m, 2m+n stéréoisomères (méso : un de moins).
Moyens mnémotechniques
  • Alcane acyclique : « 2n + 2 » hydrogènes → N = 0.
  • N = « 2C + T + 2 − H, le tout sur 2 » ; l'oxygène n'apparaît pas.
  • 1 double liaison, 1 triple liaison… ou 1 cycle : chacun compte dans N.
  • [α] = « alpha sur longueur fois concentration ».
  • Dextrogyre (+) → droite ; lévogyre (−) → gauche ; racémique → 0.
  • R/S et (+)/(−) : aucun lien.
  • 2 puissance le nombre de « centres » (C* et C=C Z/E).
  • Méso = miroir interne (plan de symétrie) : 3 stéréoisomères au lieu de 4.
