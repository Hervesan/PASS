Le fil qui relie tout : Ψ = CAΨA ± CBΨB → remplissage (2 e⁻ par OM) → OL = nliants − nantiliants2 → n + m (VSEPR) → 180° / 120° / 109,5° = sp / sp2 / sp3 → μrésultant = Σ μ → énergies en 1/r6 < liaisons H < covalentes.
Moyens mnémotechniques
  • OL = « liants moins antiliants, le tout sur 2 » ; OL = 0 → la molécule n'existe pas (He2).
  • OL 1, 2, 3 = simple, double, triple = 1, 2, 3 doublets partagés ; plus c'est multiple, plus c'est court.
  • O2 triplet : S = ½ + ½ = 1 → électrons célibataires → paramagnétique.
  • n + m = 2, 3, 4 → 180°, 120°, 109,5° ; chaque doublet libre ferme l'angle (<).
  • sp, sp2, sp3 : exposant + 1 = 2, 3, 4 orbitales, mêmes angles que VSEPR.
  • Triple = 1 σ + 2 π ; double = 1 σ + 1 π ; simple = 1 σ.
  • Keesom p·p, Debye p·α, London α·α : toutes en −k …/r6.
  • Liaison H : 20× plus faible qu'une covalente, 10× plus forte que Van der Waals.
  • 1 D = 0,333.10−29 C.m ; eau : 1,8 D (coudée, donc polaire).
